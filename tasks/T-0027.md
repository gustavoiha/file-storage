# T-0027 Stop the dockspace list request loop when it fails on the files page
Issue: #61
Request: #57
Origin: T-0026
Status: filtering

## Goal
When `GET /dockspaces` fails, opening a Generic Files dockspace (`/dockspaces/<id>`) sends that request in a tight loop (about 850 requests a second, 8,500-9,000 in 10 s, measured on PR #60 and on a main build at 93aef8c) until the tab is closed, and the page shows "Loading dockspace..." for ever. Trash, usage and `/dockspaces` send one request and show an error. A real API or network failure would hammer API Gateway and Lambda from every open tab. Pre-existing on main; found while testing T-0026.

Likely cause (testing agent's analysis, to confirm): with React Query v5, a refetch of an errored query that has no data puts it back to `pending`. `apps/web/src/pages/DockspaceWorkspacePage.tsx` then shows its loader (`!dockspace && isLoading`) and unmounts `DockspaceFilesPage`; when the request fails again it mounts `DockspaceFilesPage`, whose own `useDockspaces()` observer refetches on mount (`retryOnMount`), which starts the cycle again. Code pointers: `apps/web/src/hooks/useDockspaces.ts`, `DockspaceWorkspacePage.tsx`, `DockspaceFilesPage.tsx` (~line 303), the query client in `apps/web/src/router/AuthenticatedLayout.tsx`.

## Acceptance criteria
1. With `GET /dockspaces` failing (e.g. 500 or network error), opening a Generic Files dockspace sends a bounded number of `GET /dockspaces` requests (the initial request plus the query client's normal retries), then stops. No loop on the files page, media page, trash, usage or `/dockspaces`.
2. In that state the dockspace page shows an error (not an endless "Loading dockspace..."), with a Try again that refetches once per press and, on success, shows the right page for the dockspace's type (files page or Photos & Videos media page).
3. While the list is loading normally, the page still shows "Loading dockspace..." and then the right page for the type; Photos & Videos dockspaces still open the media page.
4. The T-0026 switcher error alert ("Couldn't load dockspaces." with Try again) keeps working and does not start a loop either.
5. A unit test reproduces the failing list on the files page route and asserts the request count stays bounded and the error is shown. Build, typecheck and tests pass.
