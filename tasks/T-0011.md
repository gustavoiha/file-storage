# T-0011 Status line confirms Move to Trash and drops stale messages
Issue: #26
Request: #5
Status: review
Origin: T-0010

## Goal
The status line above the file list (`role="status"`, fed by `moveFilesSummary` in `DockspaceFilesPage.tsx`) is not cleared or updated when a folder is moved to the trash (`onTrashFolderSubmit`) or a file is moved to the trash (`onMoveToTrash`). After a move, then Move to Trash, it keeps showing the old "Folder moved from ... to ..." message, and nothing confirms the trash. Sighted users see a stale message, and screen reader users hear no confirmation.

## Acceptance criteria
1. After a folder is moved to the trash (confirmation dialog), the status line shows a short confirmation such as "Folder moved to trash." and no earlier message remains.
2. Moving a file to the trash from the row menu also clears any stale status message (and shows a matching confirmation if that fits the design).
3. If the trash request fails, the status line does not claim success; the dialog error behaves as today.
4. The confirmation is announced through the existing `role="status"` region; focus behavior from T-0009 and T-0010 does not change.
5. Web tests cover the status after a successful folder trash, after a failed one, and that a previous move message is replaced.
