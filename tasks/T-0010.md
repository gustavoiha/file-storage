# T-0010 Visible focus on the file list after a dialog closes
Issue: #24
Request: #5
Status: testing
Origin: T-0009

## Goal
When a dialog closes and focus moves to the file list fallback (the `<ul>` with `data-dialog-focus-fallback`, `tabIndex=-1`, added in T-0009 / PR #23), nothing on screen shows where focus is. This happens after moving a file or folder out of the current folder, and after confirming Move to Trash. Keyboard users cannot see where the next Tab or arrow press will start.

## Acceptance criteria
1. When focus moves to the file list fallback after a dialog closes with the keyboard (move out of the current folder, Move to Trash confirmation), a visible focus indicator shows on the list. It should match the existing 2px accent `:focus-visible` style, at 1440 and 390 widths.
2. Mouse users do not see a stray ring on the list in the normal flow.
3. The indicator meets non-text contrast (3:1) in light and dark themes. No new serious or critical axe violations.
4. Web tests cover the fallback focus after Move to Trash.
