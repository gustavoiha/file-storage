# T-0043 Files upload "invalid upload paths" message: correct singular
Issue: #93
Request: #65
Origin: T-0039
Status: testing

## Goal
When an upload from the files page includes files whose upload paths are invalid, `apps/web/src/hooks/useDockspaceUploadDialog.ts` (`stageFiles` and `stageFolderFiles`) shows "`N file(s) had invalid upload paths and were skipped.`". For one file it reads "1 file had invalid upload paths and were skipped." (wrong number agreement). Use the correct singular and plural. Found in code review of T-0039, round 1, finding C1 (pre-existing on main).

## Acceptance criteria
1. One skipped file reads, for example, "1 file had an invalid upload path and was skipped."; several read "N files had invalid upload paths and were skipped." (wording may be refined, but correct singular/plural), in both the file and folder upload paths.
2. The message still shows where it does today, and the valid files still upload.
3. A unit test covers the singular and plural text. Build, typecheck and tests pass.
