# T-0005 Make multi-select reachable on touch phones
Issue: #5
Status: design
Origin: T-0003

## Goal
On a touch phone, the "Select {name}" checkbox shows only on hover/focus, so there is no visible way to start multi-select (and then Move several files) by touch. Give touch users a clear way in.

## Acceptance criteria
1. At 390x844 with touch, a user can start selection mode on the files page without a keyboard or hover, using a visible control (e.g. a "Select" item in the folder options menu or the row `⋯` menu, or a long-press with a visible hint). The chosen pattern is described in the PR.
2. Once in selection mode on a phone, tapping rows toggles them, the checkboxes are visible, and the selection bar (Move, clear) works as on desktop. Leaving selection mode returns to normal tap-to-preview.
3. Desktop behavior is unchanged (hover/focus reveal, click on the checkbox, keyboard). No new serious or critical axe violations. Web tests are updated and pass.
