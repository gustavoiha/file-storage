# T-0050 Uploads card keeps keyboard focus when it collapses or expands
Issue: #108
Request: #65
Origin: T-0045
Status: filtering

## Goal
The floating uploads card (shared by the gallery and the files page) loses keyboard focus when it is collapsed or expanded. Pressing Enter on "Collapse uploads" unmounts that button and `document.activeElement` becomes the page body, so a second Enter does nothing and a keyboard user has to Tab again from the top of the page. Expanding from the collapsed pill does the same. `apps/web/src/components/files/UploadsCard.tsx` only moves focus for Retry. Found while testing T-0045 (#96), round 1, finding 1 (pre-existing since T-0030, not changed by PR #103).

## Acceptance criteria
1. Collapsing the card with "Collapse uploads" (Enter, Space or click) moves focus to the collapsed pill; expanding it from the pill moves focus to "Collapse uploads". Focus never ends on the page body. Works on the gallery and the files page, on desktop and phone.
2. The focus ring shows for keyboard use only (`:focus-visible`), not after a mouse click or tap.
3. Existing focus moves are unchanged: Retry moves focus to Collapse uploads, Dismiss moves focus to Upload.
4. Unit tests cover focus after collapse and after expand. Build, typecheck and tests pass.
