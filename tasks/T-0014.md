# T-0014 Remove the folder and file counts from the current folder heading
Issue: #TBD
Request: #31
Status: new

## Goal
In a generic files dockspace (desktop layout), the current column heading shows the folder name followed by
" · N folders, M files" (rendered uppercase, e.g. "TRIP · 0 FOLDERS, 5 FILES"). The human finds this not worth
seeing at all times. Remove the counts from the heading; the folder name stays. The counts move to a folder info
panel (T-0015), which is a separate task.

Code: `apps/web/src/components/files/FileList.tsx` (`columnTitle` header, `<span className="dockspace-column__counts">`),
`apps/web/src/styles/layout.css` (`.dockspace-column__counts`), test in
`apps/web/src/tests/components/FileList.test.tsx` (heading name "trip · 1 folder, 2 files").

## Acceptance criteria
1. On the desktop files page of a generic files dockspace, the current column heading shows only the folder name
   (root label for the root): no " · ", no folder count, no file count, in any folder, including empty folders.
2. The heading's accessible name is the folder name alone (e.g. `getByRole('heading', { name: 'trip' })`).
3. The Size and Modified column labels, the per-folder-row "N files" count, the phone layout and the trash page
   are unchanged.
4. The unused `.dockspace-column__counts` style and the `columnTitle` doc comment that mentions the counts are
   removed or updated; no dead code is left.
5. Unit tests updated: the heading test asserts the name without counts, and a test asserts that no
   "folder"/"file" count text appears in the heading. Build, typecheck and tests pass.
