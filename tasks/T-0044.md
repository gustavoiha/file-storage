# T-0044 Find duplicates summary focus ring: space between ring and text
Issue: #95
Request: #65
Origin: T-0040
Status: filtering

## Goal
After a confirmed Move to trash in Find duplicates leaves Move selected to trash disabled, focus moves to the duplicates summary (`.media-duplicates__summary`, `tabIndex={-1}`, in `apps/web/src/pages/dockspaceMedia/DockspaceMediaWorkspace.tsx`), which shows a 2px accent `:focus-visible` ring (`apps/web/src/styles/layout.css`, added by T-0040). The summary has no padding, so with `outline-offset: 2px` and the 6px radius the rounded left edge of the ring touches the first character ("0 duplicate groups found."), on desktop and phone. Give the ring some space from the text. Found while testing T-0040 (#84), round 1, finding 1.

## Acceptance criteria
1. The duplicates summary's keyboard focus ring does not touch or overlap the text on desktop and phone (for example a little inline padding on the summary, or a larger offset), and is not clipped by its container.
2. The summary's layout and alignment with the content below stay visually the same when it is not focused; the ring is still shown only for keyboard focus (`:focus-visible`), not after a mouse confirm.
3. The CSS guard test for the summary focus rule (`duplicatesSummaryFocus.test.ts`) covers the change. Build, typecheck and tests pass.

Build after T-0040 (PR #88) is merged; the rule is added there.
