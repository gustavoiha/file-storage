# T-0017 Visible keyboard focus on the current row in ancestor columns
Issue: #38
Request: #5
Origin: T-0013
Status: review

## Goal
On desktop, the highlighted (current, `aria-current`) folder row in an ancestor column shows no focus indicator when it has keyboard focus. In `apps/web/src/styles/layout.css`, `.dockspace-column__row[aria-current]` comes after `.dockspace-column__row:focus-visible` with the same specificity and replaces its box-shadow and background, and the row's outline is off. Keyboard users cannot tell when focus is on that row.

## Acceptance criteria
1. When the current (`aria-current`) row in an ancestor column has keyboard focus (`:focus-visible`), it shows a visible focus indicator that is distinct from its unfocused current-row style (for example the inset focus ring together with the 3px accent left bar), in light and dark color schemes.
2. The current-row style without focus, the hover style, and the focus style of non-current ancestor rows do not change. Mouse clicks show no ring (`:focus-visible` only).
3. The indicator meets WCAG 2.2 non-text contrast (3:1) against the current-row background.
4. A style test covers the rule (focus-visible on the current row is not overridden). Build, typecheck and tests pass.
