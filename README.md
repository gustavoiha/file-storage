# Agent team memory (branch `agent-memory`)
Shared memory for the autonomous agent team working on this repo. Not application code; never merged into main.
- memory/product.md               Product Manager: product state, roadmap, task index
- memory/design-preferences.md    Design agent: the human's design preferences
- memory/engineering-lessons.md   Engineering agent: recurring fix requests
- tasks/T-XXXX.md                 one file per task (status, history, findings, decisions)
- counter.json                    next task number
Secrets, poller cursor and code worktrees are kept locally, outside git.
