# T-0048 Gallery trash result: a partial failure shows as an error
Issue: #104
Request: #65
Origin: T-0041
Status: filtering

## Goal
In the media gallery, the result of Trash selected is always shown in the blue info alert (`bulkActionMessage` is rendered with `tone="info"` in `DockspaceMediaWorkspace.tsx`), even when some files failed: "Moved 1 item to trash. 1 failed." looks like a success. Find duplicates already shows the identical text in the red error alert (T-0041, `duplicateActionMessage` is `{ message, tone }`). Already on main. Found while testing T-0041 (#85), round 1, finding 1.

Notes: build after T-0041 (PR #100) is merged; same controller (`useDockspaceMediaController.ts`) and same alert block. Reuse T-0041's `{ message, tone }` shape and `formatTrashResultMessage`.

## Acceptance criteria
1. In the gallery, a trash result where every selected file moved shows in the info style (unchanged); a result with one or more failed files ("Moved N item(s) to trash. M failed.") or a request error shows in the error style, matching Find duplicates.
2. The text is unchanged, and the alert keeps `role="alert"` in both tones.
3. Unit tests cover the info tone for a clean result and the error tone for a partial and a full failure in the gallery. Build, typecheck and tests pass.
