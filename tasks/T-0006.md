# T-0006 Visible keyboard focus ring on dockspace cards
Issue: #16
Request: #5
Status: awaiting-human
Origin: T-0004

## Goal
Make keyboard focus on dockspace cards clearly visible. Today `.dockspace-card:focus-visible` (`apps/web/src/styles/layout.css`) sets `outline: none` and only lightens the border (rgba(188,205,228,0.5)), lifts the card 2px and adds a shadow, which is hard to see on the dark background (WCAG 2.4.7 Focus Visible). Found in T-0004 test round 1 (screenshot `.agent-local/logs/T-0004/d1440-02-card-focus.png`).

## Acceptance criteria
1. On /dockspaces (desktop 1440x900 and phone 390x844), tabbing to a dockspace card or the create card shows a clearly visible focus indicator (e.g. a 2px outline with offset or a strong ring in the app's accent color, at least 3:1 contrast against the background), consistent with the focus-visible style used elsewhere in the app.
2. Mouse hover looks the same as today; the ring appears only for keyboard focus (`:focus-visible`).
3. No new axe violations on the dockspaces list; web tests pass.
