# T-0003 Accessibility fixes on the dockspace files page
Issue: #5
Status: new
Origin: T-0001

## Goal
axe-core reports issues on the generic dockspace files page that already exist on main and that the T-0001 controls repeat. Fix them.

## Acceptance criteria
1. The primary button style (e.g. the Upload button: white text on #4da8ff, 2.51:1) has at least 4.5:1 text contrast in both themes, without changing its look elsewhere more than needed.
2. No nested-interactive violation: the "Select {name}" checkbox is no longer inside the file row `<button>`. The row and the checkbox are siblings (or use an equivalent accessible pattern), and click, selection and keyboard behavior are unchanged.
3. The desktop files page has exactly one `<h1>` (e.g. the current folder or dockspace name), and the heading order stays logical. The phone layout keeps its existing h1.
4. axe-core reports no serious or critical violations on `/dockspaces/<id>` with a folder open and with the preview open. Web tests are updated and pass.
