# T-0005 Make multi-select reachable on touch phones
Issue: #15
Request: #5
Status: awaiting-human
Origin: T-0003

## Goal
On a touch phone, the "Select {name}" checkbox shows only on hover/focus, so there is no visible way to start multi-select (and then Move several files) by touch. Give touch users a clear way in.

## Acceptance criteria
1. At 390x844 with touch, a user can start selection mode on the files page without a keyboard or hover, using a visible control (e.g. a "Select" item in the folder options menu or the row `⋯` menu, or a long-press with a visible hint). The chosen pattern is described in the PR.
2. Once in selection mode on a phone, tapping rows toggles them, the checkboxes are visible, and the selection bar (Move, clear) works as on desktop. Leaving selection mode returns to normal tap-to-preview.
3. Desktop behavior is unchanged (hover/focus reveal, click on the checkbox, keyboard). No new serious or critical axe violations. Web tests are updated and pass.

## Design options (round 1)
Comment: https://github.com/gustavoiha/file-storage/issues/5#issuecomment-7038269922
Mockups: /Users/gustavoiha/Personal/file-storage/.agent-local/design/T-0005/round-1/ (generator src/gen.mjs)
All options: touch only (`(hover: none)`); desktop with a mouse unchanged. In selection mode, checkboxes show on every file row, a row tap toggles it, folders are dimmed, and row menus are hidden. Leaving returns to tap-to-preview.
1. **Select button in the phone header** (iOS style): a `Select` button next to the folder name. Selection header: Cancel / "N selected" / Select all. A full-width "Move N files" bottom bar replaces Upload. Chips, breadcrumb and uploads pill are hidden while selecting. Leave: Cancel, finishing a Move, or back. Images: https://raw.githubusercontent.com/gustavoiha/file-storage/agent-memory/design/T-0005/round-1/option-1-desktop.png, https://raw.githubusercontent.com/gustavoiha/file-storage/agent-memory/design/T-0005/round-1/option-1-phone.png
2. **Select items in the existing menus**: the row `⋯` gets "Select" (selects that file), and Folder options `⋯` gets "Select files" (nothing selected). It uses the same sticky selection bar as desktop (N files selected, Move, Cancel). Leave: Cancel, finishing a Move, or deselecting the last file. Images: https://raw.githubusercontent.com/gustavoiha/file-storage/agent-memory/design/T-0005/round-1/option-2-desktop.png, https://raw.githubusercontent.com/gustavoiha/file-storage/agent-memory/design/T-0005/round-1/option-2-phone.png
3. **Press and hold with a visible tip**: a ~500 ms hold selects the file. A dismissible tip card ("Press and hold a file to select several") shows until first use or dismissal (stored per device). A floating bottom dock shows "N selected", Move and X. Long-press no longer opens the row menu on touch (the `⋯` still does). Images: https://raw.githubusercontent.com/gustavoiha/file-storage/agent-memory/design/T-0005/round-1/option-3-desktop.png, https://raw.githubusercontent.com/gustavoiha/file-storage/agent-memory/design/T-0005/round-1/option-3-phone.png
