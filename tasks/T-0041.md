# T-0041 Gallery trash messages: correct plurals, success not shown as an error
Issue: #85
Request: #65
Origin: T-0034
Status: testing

## Goal
The media gallery's trash copy has wrong number agreement and the Find duplicates success message looks like an error. Today: "Moved 1 items to trash." (`useDockspaceMediaController.ts`, gallery and duplicates), "1 items selected for trash." (Find duplicates footer) and "This will move 1 selected media files to trash." (trash dialog) in `DockspaceMediaWorkspace.tsx`. In Find duplicates, `duplicateActionMessage` is rendered with the default (red, error) `Alert`, while the gallery's `bulkActionMessage` already uses `tone="info"`. Already on main. Found while testing T-0034 (#75), round 1, finding 3.

Notes: T-0039 fixes another plural in the same controller (skipped-files message) and T-0030 (PR #73) changes the same files: build after T-0030 is merged and rebase on main before the PR; can be done together with T-0039 if both are dispatched at once.

## Acceptance criteria
1. Singular and plural are correct in the trash result ("Moved 1 item to trash." / "Moved N items to trash.", including the "M failed." variant), the duplicates footer ("1 item selected for trash.") and the dialog description ("This will move 1 selected media file to trash.").
2. A successful result in Find duplicates shows in the neutral info style, like the gallery's; a result with failed items may stay in the error style.
3. Unit tests cover singular and plural text and the info tone. Build, typecheck and tests pass.
