# T-0033 Gallery shows a file uploaded from the gallery without a reload
Issue: #74
Request: #65
Origin: T-0031
Status: testing

## Goal
In a media dockspace, a file uploaded with the gallery's Upload button does not appear in the gallery until the page is reloaded or the user returns to the tab: the Uploads panel shows the upload as done, but no `/media` request is sent. Already on main: `useUploadFile` in `apps/web/src/hooks/useFiles.ts` invalidates `files` and `media-duplicates` on success, but not `media` (nor the album queries), and the gallery uses that hook (`apps/web/src/pages/dockspaceMedia/useDockspaceMediaController.ts`). Found while testing T-0031 (#69), round 1, finding 1.

Notes: the gallery query is infinite and paged (120 per page), so a refetch re-requests every loaded page. Prefer one invalidation when a batch of uploads finishes over one per file, and keep T-0029/T-0031 paging behaviour (one request at a time, status text only near the end). Coordinate with T-0030 (gallery layout), which touches the same files.

## Acceptance criteria
1. After an upload from the media gallery finishes, the new file appears in the gallery without a reload or tab switch (desktop and phone).
2. Uploading several files at once refreshes the gallery without one full gallery refetch per file (at most one refetch after the batch, or an equivalent targeted update).
3. Uploads from the files page (generic dockspaces) behave as before.
4. A test covers that a successful upload refreshes the media query. Build, typecheck and tests pass.

## Code review (round 1)
