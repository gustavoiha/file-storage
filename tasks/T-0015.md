# T-0015 Folder info panel from the folder action menu
Issue: #33
Request: #31
Status: design

## Goal
Give each folder an "Info" panel that shows details about that folder, starting with what was removed from the
heading in T-0014: how many folders and files it directly contains. The human suggested reaching it from the
action menu each folder has (today: Rename, Download, Move, Move to Trash in the folder row menu of
`apps/web/src/components/files/FileList.tsx`; on phone the menu opens by press-and-hold or Shift+F10).

Data at hand: `FolderRecord` has name, fullPath, createdAt, updatedAt; the page has direct file counts per child
folder (`folderFileCounts`); a subfolder count for a child folder may need its folder-children query.
Design decides the panel form (dialog, side panel like the file preview, or popover), its contents and whether
the current folder also gets the entry (e.g. from "Folder options" / "Dockspace options").

## Acceptance criteria
1. Every folder row's action menu (desktop `⋯` / right-click, phone press-and-hold) has an "Info" item (final
   wording from design) that opens the folder info panel for that folder.
2. The panel shows at least: folder name, its path, number of direct subfolders, number of direct files; plus
   any other fields the chosen design includes (e.g. created/modified dates, total size if available).
3. Counts are correct for empty folders, folders with only subfolders, and folders with only files, and use
   singular/plural correctly ("1 file", "2 folders").
4. The panel can be closed with Escape, a visible Close button and (if a dialog) the backdrop; focus moves into
   the panel on open and returns to the opener on close (T-0009 pattern). It has an accessible name and passes axe.
5. Works in the desktop and phone layouts; while counts load, the panel shows a loading state, and an error state
   if the request fails.
6. Unit tests cover the menu item, the counts and the open/close focus behavior. Build, typecheck and tests pass.

## Design options (round 1)
Comment: https://github.com/gustavoiha/file-storage/issues/33#issuecomment-7066704308
Common to all: "Info" is the first item (then a separator) in every folder row menu (desktop `⋯`/right-click, phone press-and-hold, Shift+F10). Counts use singular/plural. Name, path and dates come from FolderRecord; counts (and size) load from the folder's listing, with loading and error states.

### Option 1: Info dialog (modal)
- Modal `dockspace-dialog` titled "Folder info": name card with path, Contains "2 folders, 6 files", Created, Modified, Close. Same centered dialog on phone.
- Current folder: no entry (reach it from its row one level up).
- A11y: role=dialog, aria-modal, labelled by heading; focus to Close, trapped; Esc/Close/backdrop close; focus returns to row `⋯` or row (T-0009). Loading "Counting…" (status), error alert with Try again.
- Images: https://raw.githubusercontent.com/gustavoiha/file-storage/agent-memory/design/T-0015/round-1/option-1-desktop.png , https://raw.githubusercontent.com/gustavoiha/file-storage/agent-memory/design/T-0015/round-1/option-1-phone.png

### Option 2: Info in the right-hand panel (file-preview slot)
- 420px right column using the preview frame: header (folder icon, name, Open, Close X); "Folder info" label; count tiles (folders/files); Files size (direct files), Created, Modified, Location; Esc hint. One detail panel at a time (opening a file swaps back to preview). Row highlighted like a previewed file.
- Current folder: "Folder info" first in Dockspace options `⋯` (desktop) and Folder options `⋯` (phone).
- Phone: full page like the phone file preview, back button, folder name as h1.
- A11y: aside labelled by the name heading; focus to Close on open; Esc/Close/back return focus to opener. Skeletons + "Counting contents…" status; error alert with retry.
- Images: https://raw.githubusercontent.com/gustavoiha/file-storage/agent-memory/design/T-0015/round-1/option-2-desktop.png , https://raw.githubusercontent.com/gustavoiha/file-storage/agent-memory/design/T-0015/round-1/option-2-phone.png

### Option 3: Info card (popover) anchored to the row
- Non-modal card replacing the row menu at the same spot: name, "2 folders · 6 files", Modified, Created, parent path; Close X. Phone: full-width card under the pressed row.
- Current folder: new (i) button next to the column heading (desktop) / title (phone), opening the same card.
- A11y: role=dialog aria-modal=false labelled by name; (i) has aria-haspopup=dialog + aria-expanded; focus to Close; Esc/Close/click outside close and return focus to opener. Loading "Counting…" status; error alert.
- Images: https://raw.githubusercontent.com/gustavoiha/file-storage/agent-memory/design/T-0015/round-1/option-3-desktop.png , https://raw.githubusercontent.com/gustavoiha/file-storage/agent-memory/design/T-0015/round-1/option-3-phone.png
